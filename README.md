# Cobblemon TS

[English](#english) | [中文](#中文)

## English

A Cobblemon enhancement mod that adds utility items, data-driven UI, and reforge-style battle mechanics to your blocky Pokémon adventure.

### 🎒 Items

| Item | Function |
|------|----------|
| **Shiny Charm** | Boosts shiny Pokémon encounter rate |
| **Oval Charm** | Accelerates egg hatching |
| **Exp. Charm** | Increases battle EXP gain |
| **Catching Charm** | Improves Poké Ball catch rate |
| **Exp. All** | Shares battle EXP with the entire party |
| **Gold Crown** | Grants perfect IVs (preserves base IVs for Hidden Power type calculation) |
| **Pokémon Editor** | Creative-mode tool: right-click to edit your party, left-click to edit another player's party |
| **Poké Bag** | Portable item storage: left-click to toggle auto-collect, right-click to open |
| **Lucky Blocks** | Break to spawn random Pokémon or items (Legendary, Shiny, Ultra Beast, and Item variants) |

### 📊 Data-Driven UI

- **HUD Overlay**: Real-time party status, charm activation, and held item info
- **Charm Management Panel**: Visual toggle for each charm with effect display
- **Held Item Management**: Drag-and-drop held items directly in the party panel
- **Enhanced Battle Info**: Catch rate and IV data displayed in battle UI

### ⚔️ Reforge-Style Battle Throw

- Right-click to open Poké Bag and throw balls during battle
- Catching Charm boost is compatible with Catch Rate Display mod

### Dependencies

- **NeoForge** 1.21.1
- **Cobblemon** ≥ 1.7.3

### Optional Compatibility

- [Catch Rate Display](https://www.curseforge.com/minecraft/mc-mods/catch-rate-display) — catch rate display mod
- [jecharacters](https://www.curseforge.com/minecraft/mc-mods/jecharacters) — Pinyin search support

## 中文

Cobblemon 辅助增强模组，为你的方块宝可梦之旅添加实用道具、数据化 UI 和重铸版战斗体验。

### 🎒 道具系统

| 道具 | 功能 |
|------|------|
| **闪耀护符** | 提升闪光宝可梦遭遇几率 |
| **圆形护符** | 加速宝可梦蛋孵化 |
| **经验护符** | 战斗经验值加成 |
| **防晃护符** | 提升精灵球捕获率 |
| **高级学习装置** | 战斗经验全队共享 |
| **金色王冠** | 赋予宝可梦完美个体值（不修改基础 IV，支持觉醒力量类型计算） |
| **宝可梦编辑器** | 创造模式工具，右键编辑自己队伍，左键编辑其他玩家队伍 |
| **道具袋** | 便携道具收纳，左键切换自动收集，右键打开管理界面 |
| **幸运方块** | 破坏后随机生成宝可梦或物品（含传说、闪光、异兽、物品四种变体） |

### 📊 数据化 UI

- **HUD 覆盖层**：实时显示队伍状态、护符激活情况、携带物信息
- **护符管理面板**：可视化开关各个护符，一键查看效果
- **携带物管理**：队伍界面直接拖拽/更换宝可梦携带物品
- **对战信息增强**：战斗界面显示捕获率、个体值等详细数据

### ⚔️ 重铸版战斗丢球

- 战斗中右键打开道具袋快速选择精灵球投掷
- 防晃护符捕获率提升兼容 Catch Rate Display 模组，正确显示提升后的捕获率

### 依赖

- **NeoForge** 1.21.1
- **Cobblemon** ≥ 1.7.3

### 可选兼容

- [Catch Rate Display](https://www.curseforge.com/minecraft/mc-mods/catch-rate-display) — 捕获率显示模组
- [jecharacters](https://www.curseforge.com/minecraft/mc-mods/jecharacters) — 拼音搜索支持
